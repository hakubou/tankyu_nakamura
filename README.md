# 回転型倒立振子（Furuta pendulum）

Damiao **DM-J4310-2EC V1.1** と Quanser **QUBE-Servo 2** の振子モジュールを組み合わせた
回転型倒立振子。振り上げ（スイングアップ）から倒立保持までを自動で行う。

学校の探究課題として 2026 年 8 月に製作したもの。

## 到達点（2026-08-28 時点）

| 項目 | 実績 |
|---|---|
| スイングアップ成功率 | **82.8%**（トルク上限 0.8 N·m、29 回） |
| 振り上げ所要時間 | 中央値 1〜2 秒 |
| 倒立保持 | **最長 61.6 秒**（スイングアップからの連続動作） |
| 失敗の内訳 | すべて「アーム角が ±140° に到達」。**振子の姿勢制御自体の失敗は 0 件** |

制御周期は約 600 Hz。振子角は STM32 のハードウェアエンコーダで読み、
13 バイトのフレームで PC へ 1 kHz 送信する。制御則（オブザーバ＋LQR、
エネルギー整形則によるスイングアップ）はすべて PC 側の C# で動く。

## 動かす

`.NET SDK 10.0` が必要。

```
cd モータ制御プログラム一式_20260806/csharp
dotnet build
dotnet test
dotnet run --project src/SwingUp -- COM4 COM8 30 1.0 25 10
```

引数は左から「振子ポート・モータポート・SwingGain・振り上げトルク上限・
キャッチ角度・最小射影法の c・保持秒数」。**COM ポート番号は環境ごとに変わる。**

`model/FurutaGains.cs` を再生成したら、`csharp/src/DamiaoCan/` へのコピーが毎回必要。

## 実測した主なパラメータ

| 記号 | 値 | 備考 |
|---|---|---|
| J_r | 2.13×10⁻³ kg·m² | アーム慣性。高周波・小振幅加振で同定。質量からの概算の 5.3 倍で、差は減速機の反射ロータ慣性 |
| τ_c | 0.109 / 0.143 N·m | クーロン摩擦（正転／逆転）。30% の非対称あり |
| b_r | 0.027 N·m·s/rad | アーム側の粘性 |
| 振子の固有振動数 | 1.70 Hz | 実測。モデル予測 1.746 Hz と 3% 以内で一致 |
| 不安定極 | 11.05 rad/s | 時定数 90 ms |

## 設計上の方針

- 制御の実装はすべて **C#（.NET 10）**。Python は運動方程式の導出とゲイン計算のみに使い、
  **成果物は数値行列として C# に定数で埋め込む**。実行時に Python を呼ばない
- マイコン側は **エンコーダを読んで送るだけ**。制御ロジックは載せない
- MIT モードで `kp=kd=0` とし、`t_ff` だけでトルクを与える純トルク制御

## 安全上の注意

- **アームを 1 回転させない**（配線が引っ掛かる）
- 実行前にアームと振子の可動範囲に物・手・ケーブルが無いことを確認する
- 電源スイッチにすぐ手が届く状態で実行する
- 実行中に他のウィンドウをクリックすると、Windows の電源スロットリングで
  制御周期が 575 Hz → 130 Hz に落ちる。**計測中は裏で何も動かさない**
