1. 背景と目的
  • 倒立振子は不安定・非線形・劣駆動が同時に成立する制御の標準問題。
  • アームの先端で振子を支える回転型（古田式）は、古田らが 1992 年に提案した形式。
  • 台車型は直線レールの長さが可動範囲を縛る。回転型（古田式）はアームが無限に回れるため、振り上げに使える距離の制約がない。
  • 入力はアーム軸のトルク τ ただ一つ、制御したい自由度はアーム角 θ と振子角 α の二つ。
  • 目的：実機を製作し、モデルから設計した制御則の切替によって振り上げ → 捕捉 → 倒立保持を成立させる。

3. 運動方程式

Lagrange 法で導出（Coriolis 項の符号を誤らないよう数式処理系で機械的に展開）。

P₁ = J_r + m_p L_r²　　P₂ = J_p + m_p l_p²
P₃ = m_p L_r l_p　　　P₄ = m_p l_p → 未知量が 4 つに集約される
  • sin²α：姿勢によって有効慣性が変わる（非線形の源）。
  • P₃ cos α：アームと振子の連成。振子を動かせる唯一の経路。
  • θ は循環座標（重力の復元力を持たない）→ 不安定なのは α だけ。
4. パラメータ同定
  • 振子側：自由振動の周期と対数減衰から J_p、b_p を実測。
  • アーム側：±5°・4〜9 Hz で正弦加振。慣性トルクは sin 位相、摩擦は cos 位相で直交するため、τ_rms² を ω⁴ の一次式に回帰すれば傾きから J だけを取り出せる。
  • 検証：アームを正弦駆動して周波数を掃引。振子が共振すると反力がモータのトルクに現れる（図3）。
図3　アームを正弦駆動したときのトルク RMS（±8°、実測）。慣性負荷による単調増加の上にピークとディップの対が乗る。その遷移点が振子の固有振動数。
【要点 ①】QDD の代償 ― 反映ロータ慣性 アーム慣性の実測値 J_r = 2.13 × 10⁻³ kg·m² は、機構部品の質量から見積もった値の 5.3 倍。 減速比 10:1 によりロータ慣性が出力軸から 10² = 100 倍に見えるため。
固有振動数は実測 1.70 Hz、自由振動からの予測 1.745 Hz と 3% 以内で一致し、モデルの正しさを裏づけた。
5. 線形化と不安定性
α = 0 まわりで線形化：　ẋ = A x + B u　　x = ( θ, α, θ̇, α̇ )ᵀ
Δ = P₁P₂ − P₃² > 0　　A₄₂ = P₁P₄g / Δ　　B = ( 0, 0, P₂/Δ, −P₃/Δ )ᵀ
【要点 ②】不安定さを時間で測る A の固有値は { 0,　+11.1,　−9.2,　−14.3 } rad/s。
不安定極 λ = 11.1 rad/s → 時定数 90 ms。90 ms 放置すると誤差が e 倍になる。 制御周期・通信遅れ・センサ分解能の要求は、すべてこの一つの数字から逆算した。

オブザーバ極は −82 ± 81j。前進 Euler 法の数値安定条件から dt < 12.4 ms が要求される（7 章で実測と照合）。

6. 制御器設計

6-1　倒立保持：LQR ＋ カルマンフィルタ

AᵀP + PA − PBR⁻¹BᵀP + Q = 0　　u = −K x̂,　K = R⁻¹BᵀP
  • 重み Q は Bryson 則（許容偏差の逆二乗）で決定。
  • K = ( −5.00, −18.87, −1.53, −1.45 )、閉ループ極 −179.7 / −38.9 / −5.2 ± 3.4j。
  • 角速度は差分でなく推定する。0.176° の量子化値を微分するとノイズが乗るため。

6-2　振り上げ：エネルギー整形

u = k_e ( E − E_top ) · sign( α̇ cos α )　　k_e = 30
  • V = ½(E − E_top)² とおくと V̇ ≤ 0。エネルギーは単調に目標へ近づく。
  • ただし真上への到達は理論上は無限時間かかる → 捕捉の切替が原理的に必要。
  • アーム引き戻し項（|θ| > 30° で Kp = 5.0）を併用。無いと 0.4 秒で可動端 ±140° に達する。
【要点 ③】6-3　切替：最小射影法 W(x) = min ( V(x),　(E − E_r)² + c )　　V(x) = xᵀP x c = 10 とすると保証角は |α| ≤ √( c (P⁻¹)₂₂ ) = 55.1°。 従来の発見的な条件（|α| < 25° かつ |α̇| < 3.0）を、Lyapunov 関数から計算した判定に置き換えた。

6-4　摩擦補償

  • 静止摩擦 0.147 N·m。平衡点では必要トルクが 0 に近づくので必ず不感帯に入る。
  • u_f = τ_c tanh( θ̇ / ε )　正転 0.109 / 逆転 0.143 N·m、ε = 0.15 rad/s。

8. まとめと今後
  • 理論値と実機が一致した 3 点　不安定極の時定数 90 ms ／ 数値安定限界 12.4 ms（実機の破綻境界と一致）／ 固有振動数 1.70 Hz（予測 1.745 Hz）。
  • QDD の代償を実測で確認　反映ロータ慣性によりアーム慣性が見積りの 5.3 倍。設計段階で見落としやすい量である。
  • 切替を計算で決めた　最小射影法により、捕捉条件を発見的な閾値から Lyapunov 関数に基づく判定へ置き換えた。最長で 61.6 秒の連続倒立を達成。
  • 今後　倒立保持中にアーム角が原点へ戻らず 27〜35° に居着く現象の解明、外乱応答の定量評価、制御周期の崩壊への対策。
