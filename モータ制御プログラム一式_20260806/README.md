---

## これは何か

Damiao のモータ **DM-J4310-2EC V1.1** を、PCから CAN 通信で回すためのプログラムです。
公式ソフト（達妙調試助手）は配布元が 404 で入手できなかったため、
**Python から直接 CAN フレームを送受信する方式**で実現しています。

実測: 速度モードで 0.5 rad/s を指定し、12.6秒で **359.5〜359.6度（＝1.00回転）**。
速度のばらつきはほぼ無し。

## 必要なもの

### ハードウェア

| 品目 | 備考 |
|---|---|
| DM-J4310-2EC V1.1 モータ | CAN ID は今回 **4** に設定済み |
| 24V 直流電源 | OMRON S8FS-G24024（240W級）を使用。8〜10A あれば十分 |
| USB-CAN 変換 | USB-CAN Analyzer V8.00（120Ω終端が内蔵されている） |
| 配線 | XT30(2+2) ケーブル（モータに付属） |

### 配線

```
        ┌── VCC / GND ──→ 24V電源
モータ ─┤  (XT30(2+2))
        └── CAN_H / CAN_L ──→ USB-CAN変換 ──USB──→ PC
```

※ GND は電源側と USB-CAN 側で共通にすること。

### ソフトウェア


Python 3.14.6 で確認。CH340 のドライバが必要ですが、Windows 11 なら
USB-CAN を挿すと自動で入ることが多いです。

## 動かす手順

### 1. COMポート番号を調べる

デバイスマネージャー →「ポート (COM と LPT)」に
`USB-SERIAL CH340 (COM3)` のように表示されます。**この番号を控えてください。**
表示されない場合はドライバが入っていません。

### 2. 設定を自分の環境に合わせる

`demo_1回転.py` の冒頭を書き換えます。

```python
PORT     = "COM3"    # ← 手順1で調べた番号
MOTOR_ID = 4         # ← モータのCAN ID
```

### 3. 安全確認（必ず）

- モータが固定されているか
- 出力軸の回転範囲に手・物・ケーブルが無いか
- 電源スイッチにすぐ手が届くか

### 4. 実行

```bash
py demo_1回転.py
```

通信確認 → モード確認 → 1回転、まで自動で行います。

## つまずきポイント（先に読んでおくと時間を節約できます）

### 動かないときは、まず 24V 電源を疑う

**一番時間を無駄にした原因がこれです。** 電源が入っていないのに
「Enable が効かない」と悩み続けました。
モータのLEDが**赤＝失能、緑＝使能（通電中）**なので、まずLEDを見てください。

### MITモードでは kp を 0 にしてはいけない

`kp = 0` だと力が発生せず、モータはまったく動きません。
指令は届いていて、フィードバックも返ってくるのに動かないので原因が分かりにくいです。
今回は `kp = 20`、`kd = 2.0` で安定しました。

### 目標位置を遠くに置くと急加速する

MITモードで「29度先」を一度に指定したところ、非常に速く動いて危険でした。
目標との差が大きいほど強い力が出るためです。
**目標を5msごとに少しずつ進める**ことで、滑らかな低速回転になります
（`mit_move()` に実装済み）。

### 一定速度で回すだけなら速度モードが楽

| | MITモード | 速度モード |
|---|---|---|
| 指令 | 位置・速度・kp・kd・トルクの5要素 | 速度 (rad/s) のみ |
| 実装 | ゲイン調整と軌道生成が必要 | 値を1つ送るだけ |
| エンコーダ一周時 | 位置が飛んで誤停止した | 影響なし |

制御モードは **CAN経由で変更でき、フラッシュ保存すれば電源を切っても維持されます**
（`set_mode()` に実装済み）。今回は速度モード(3)に設定してあります。

### USB-CAN を開いた直後は 0.5 秒待つ

すぐに送信すると応答を取りこぼします。モジュール側で対処済みです。

### Enable / Disable はモータIDあてに送る

`0x104` や `0x204` に送っても受け付けられません。必ずモータID（今回は `0x004`）へ。

## 簡単な使い方

```python
from damiao_can import Motor

with Motor(port="COM3", motor_id=4) as m:
    print(m.read_status())          # 状態を読む（動かない）
    m.spin(speed=0.5, turns=1.0)    # 0.5 rad/s で1回転
```

`with` を抜けると**必ず失能**されます。途中でエラーが出ても
モータは安全な状態（非通電）に戻るようになっています。

### よく使う操作

```python
m.read_status()                 # 位置・速度・エラー・温度を取得
m.scan()                        # 応答するモータのCAN IDを探す
m.read_mode()                   # 制御モードを確認 (1=MIT, 2=位置速度, 3=速度)
m.set_mode(3)                   # 速度モードへ変更して保存
m.spin(speed=0.5, turns=2.0)    # 2回転
m.spin(speed=-0.5, turns=1.0)   # 逆回転
m.mit_move(delta_rad=1.57)      # MITモードで90度動かす
```

## 主な仕様（データシートより）

- 定格 24V / 2.5A、ピーク 7.5A、過電流保護は 9.8A 以下推奨
- 定格トルク 3N·m、ピーク 7N·m、減速比 10:1
- 制御は CAN 1Mbps・標準フレーム
- Enable: `FF FF FF FF FF FF FF FC` / Disable: `FF FF FF FF FF FF FF FD`

詳しい背景や検証の経緯は、報告書 `モータ動作検証報告_20260806.pdf` を参照してください。
